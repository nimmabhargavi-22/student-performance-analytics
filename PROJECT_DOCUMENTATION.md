## 3. Objective
The objective of this project is to analyze student academic performance using Python, NumPy, and Pandas. The system calculates total marks, average marks, grades, and pass/fail results and identifies top-performing students.

## 4. Technologies Used
- Python
- NumPy
- Pandas
- CSV file handling
- Visual Studio Code

## 5. Dataset Description
The dataset contains 20 student records with the following fields:
- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- AI marks
- Attendance

## 6. Implementation
The program reads student data from `students.csv` using Pandas. It calculates total and average marks for each student and assigns grades using a reusable Python function. NumPy is used to determine pass/fail results based on subject marks.

The program also calculates class statistics, subject-wise averages, and identifies top-performing students. The final analysis is saved to `student_performance_report.csv`.

## 7. Features
1. Reads student data from a CSV file.
2. Calculates total and average marks.
3. Assigns grades automatically.
4. Determines pass/fail results.
5. Calculates class average, highest average, and lowest average.
6. Displays subject-wise averages.
7. Identifies top-performing students.
8. Saves the analysis report as a CSV file.
