# Student Performance Analytics System

## Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student marks and attendance. It calculates total marks, averages, grades, pass/fail results, and identifies top-performing students.

## Objectives
- Analyze student academic performance.
- Calculate total marks and average marks.
- Assign grades based on average marks.
- Identify pass and fail students.
- Calculate subject-wise averages.
- Find the highest and lowest student averages.
- Identify top-performing students.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV (Comma-Separated Values)

## Project Files
- `main.py` – Contains the Python program.
- `students.csv` – Contains student details, subject marks, and attendance.
- `student_performance_report.csv` – Stores the analyzed results.

## Dataset Description
The dataset contains 20 student records with the following fields:
- Student ID
- Name
- Department
- Python marks
- Mathematics marks
- AI marks
- Attendance

## Features
1. Reads student data using Pandas.
2. Calculates total and average marks.
3. Assigns grades based on averages.
4. Determines pass/fail results using NumPy.
5. Displays class statistics.
6. Calculates subject-wise averages.
7. Identifies top-performing students.
8. Saves the results into a CSV report.

## How to Run
1. Install Python.
2. Install the required libraries:
   `py -m pip install numpy pandas`
3. Keep `main.py` and `students.csv` in the same folder.
4. Run the program:
   `py main.py`

## Expected Output
The program displays student performance details, class statistics, subject-wise averages, pass/fail summary, and top-performing students. It also generates `student_performance_report.csv`.

## Conclusion
This project demonstrates how Python, NumPy, and Pandas can be used to analyze student performance and generate a useful report.
